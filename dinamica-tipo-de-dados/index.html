Tipos de Dados

Arraste cada carta para a categoria correta.
Dica: Pense no “formato” do registro: tabela (campos fixos), padrão flexível (com marcas/estrutura) ou conteúdo livre (texto, áudio, imagem).

⚡
CARTAS PARA CLASSIFICAR

📊
ESTRUTURADOS

Campos fixos (tabelas, colunas, cadastros)

🧾
SEMI-ESTRUTURADOS

Há padrão, mas é flexível (JSON, XML, logs)

📁
NÃO ESTRUTURADOS

Conteúdo livre (texto, imagem, áudio, vídeo)
Estruturado é fácil de “contar”. Semi-estruturado é fácil de “ler por padrão”. Não estruturado é rico em contexto — mas exige organização para virar insight.
Planilha de presença (data, turma, aluno, status) Ex.: colunas fixas e regras de preenchimento
Tabela de matrículas (aluno, curso, data, situação) Ex.: registro em banco relacional
Cadastro de empresas atendidas (CNPJ, segmento, município) Ex.: campos padronizados
Notas por disciplina (aluno, avaliação, nota, frequência) Ex.: tabela com métricas
Registro de chamados (ID, data, área, status) Ex.: campos obrigatórios
Inventário de equipamentos (patrimônio, local, responsável) Ex.: base tabular
Formulário online exportado em JSON Ex.: chaves/valores, estrutura flexível
Arquivo XML de integração (cadastro + tags) Ex.: estrutura marcada por tags
Logs de acesso (timestamp, usuário, evento) Ex.: padrão repetido em texto
Evento de sistema em formato “key=value” Ex.: estrutura parcial dentro do texto
E-mail padronizado de notificação do sistema (assunto + campos) Ex.: template com partes estruturadas
Registro de API (payload JSON com campos opcionais) Ex.: estrutura, mas com variações
E-mail de reclamação escrito livremente Ex.: texto com contexto, sem padrão fixo
Comentário aberto em pesquisa de satisfação Ex.: resposta em linguagem natural
Áudio de atendimento ou ligação gravada Ex.: conteúdo em voz
Imagem de documento escaneado Ex.: informação está “dentro” da imagem
Vídeo de aula / treinamento Ex.: conteúdo multimídia
Foto de um equipamento com defeito Ex.: evidência visual
